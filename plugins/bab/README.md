# bab

bab은 Claude Code와 Codex에서 쓰는 개발 작업 스킬 모음입니다.
바꿀 동작을 이슈에 정하고, 저장소의 wiki를 기준으로 구현한 뒤 PR에서 변경과 검증 결과를 확인합니다.

[English](https://github.com/freevue/bab-skill/blob/main/README.md) · [한국어](https://github.com/freevue/bab-skill/blob/main/README.ko.md)

[설치](https://github.com/freevue/bab-skill/blob/main/README.ko.md#설치) · [첫 작업](https://github.com/freevue/bab-skill/blob/main/README.ko.md#빠른-시작) · [변경 이력](https://github.com/freevue/bab-skill/blob/main/docs/guide.md#변경-이력) · [릴리스 노트](https://github.com/freevue/bab-skill/releases)

## 처음 사용하기

1. [설치 안내](https://github.com/freevue/bab-skill/blob/main/README.ko.md#설치)에 따라 사용할 에이전트에 bab을 설치합니다.
2. 대상 프로젝트에서 새 채팅을 열고 `bab:setup`을 실행합니다. GitHub 라벨 설치도 요청합니다.
3. [첫 작업 예시](https://github.com/freevue/bab-skill/blob/main/README.ko.md#빠른-시작)를 따라 변경 요청, 내용 확정과 구현을 진행합니다.

## 더 알아보기

[전체 스킬 목록](https://github.com/freevue/bab-skill/blob/main/docs/workflow.md#스킬-목록)에서 작업에 맞는 스킬을 찾습니다.
저장소 연결과 선택 설정은 [상세 가이드](https://github.com/freevue/bab-skill/blob/main/docs/guide.md)에 있습니다.

시각화는 wiki 스킬에 요청합니다. 필요한 관점은 [작성 기준](skills/wiki/references/visualization.md)과 [여덟 예시](skills/wiki/references/visualization-examples.md)에서 확인합니다.
기존 설치는 [업데이트 절차](https://github.com/freevue/bab-skill/blob/main/docs/guide.md#플러그인과-ci-업데이트)를 따릅니다.
