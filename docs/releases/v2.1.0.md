# bab v2.1.0

v2.1.0은 기존 스펙을 사람이 함께 검토할 목표로 묶는 선택형 마일스톤 관리를 추가합니다.

## 변경 사항

- `bab:milestone`을 기존 열린 스펙의 목표별 정리와 마일스톤 도입을 위한 셋업으로 추가했습니다.
- GitHub 마일스톤이 목표·범위·완료 기준과 소속의 정본입니다. `.bab/milestones.json`은 대상 저장소와 현재 번호를 기록합니다.
- spec은 목표에 맞는 소속을 정합니다. sync는 현재 묶음의 확정 이슈 하나를 진행하고 issues는 목표별 현황을 보여줍니다.
- 현재 목표가 없거나 닫혔거나 선택할 이슈가 없으면 대기합니다. 다음 묶음으로 자동 이동하지 않습니다.
- 다른 묶음의 진행 중 이슈도 전체 진행 상한과 wiki 경로 보호에 포함합니다.
- 이슈 목록을 한 건씩 스트림으로 읽도록 고쳤습니다. 큰 응답의 ENOBUFS를 방지하고 전체 조회 성공 뒤에만 작업을 선택합니다.
- README와 가이드를 두 언어로 정리했습니다. 도입 예시, 스킬별 사용, 대기와 사람의 결과 검토를 설명합니다.

## 호환성과 업데이트

기존 프로젝트는 `.bab/milestones.json`이 없으면 같은 방식으로 작업합니다.
스펙 필수 항목과 확정 절차, 이슈 상태, wiki 종류와 드리프트 검사 계약은 유지합니다.
마일스톤 소속이 생겨도 스펙이 자동 확정되거나 구현이 시작되지는 않습니다.

공개 후에는 플러그인과 대상 저장소의 GitHub Actions를 각각 v2.1.0으로 갱신합니다.
두 manifest와 저장소·setup workflow 참조는 2.1.0입니다.
기존 지침과 템플릿은 setup이 덮어쓰지 않습니다. dry-run의 차이를 확인하고 필요한 내용만 반영합니다.
마일스톤을 도입하려면 갱신 후 `bab:milestone`으로 기존 스펙을 정리합니다. 일반 setup은 이를 자동 도입하지 않습니다.

[한국어 사용 가이드](../guide.ko.md#마일스톤)와 [영문 사용 가이드](../guide.md#milestones)는 같은 흐름을 설명합니다.

## 검증

macOS, Node.js v24.14.0에서 버전 참조와 문서를 갱신한 뒤 검사했습니다.

| 검사 | 결과 |
| --- | --- |
| 전체 회귀 | `node --test test/*.test.mjs`, 176건 통과. 실패·건너뜀 없음 |
| 패키지 일치 | 전체 회귀에서 두 manifest와 저장소·setup workflow의 버전 참조 일치 확인 |
| wiki 구조·형상 | 명세 42페이지, 불일치와 미검증 페이지 0건 |
| 한글 문장 | README·가이드·릴리스 문서 위반 0건 |
| 문서 링크 | 변경 문서 27개의 로컬 링크 274개와 명시 앵커 검사 통과 |
| 변경 형식 | `git diff --check` 통과 |

전체 회귀 로그는 이번 작업의 임시 경로 `/private/tmp/bab-31-full.log`에 보관했습니다.
기능 구현 단계의 근거와 미검증 항목은 [마일스톤 검증 기록](../verification/milestones.md)에 있습니다.
원격 CI, 실제 프로젝트 도입과 설치한 플러그인의 로딩은 이번 결과에 포함하지 않습니다.
