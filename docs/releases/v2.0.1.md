# bab v2.0.1

v2.0.1은 v2.0.0의 플러그인 동작과 공개 계약을 유지하는 저장소 검사 유지보수 업데이트입니다.

## 변경 사항

- 회귀 workflow와 사용 안내가 `node --test test/*.test.mjs`만 실행하도록 고정했습니다.
- 회귀 테스트가 두 플러그인 manifest, 저장소 workflow, setup workflow의 버전 참조 일치를 확인합니다.
- README와 설치·업데이트 가이드를 v2.0.1 기준으로 정리했습니다.

## 업데이트

공개 후 플러그인과 대상 저장소의 GitHub Actions를 각각 v2.0.1로 갱신합니다.
기존 setup은 파일을 덮어쓰지 않으므로 dry-run에서 차이를 확인한 뒤 필요한 내용을 반영합니다.
Rust 지원 범위와 v2.0.0에서 도입한 공개 검사 계약은 [v2.0.0 릴리스 노트](v2.0.0.md)를 따릅니다.
