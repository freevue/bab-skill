## 의미 대조와 남은 범위

변경 범위의 로컬 룰·명세·실제 코드·완료 기준을 읽기 전용으로 대조했습니다.
변경 범위에서 High 위반을 발견하지 않았습니다.
앞서 완료한 실행 기록은 입력이 같은 경우 재사용했습니다.


확장자 판정을 선언 해석 전에 적용합니다.
문서 구조·필수 내용·링크·파일 존재 검사는 미지원 언어에도 유지합니다.
실제 위반과 미검증이 함께 있으면 실제 위반을 우선하되 미검증 근거를 보존합니다.
이슈 감시는 검사 완료 경로만 처리하고 미검증과 미확인 대상은 보존합니다.
변경한 유닛·정책·기능 명세의 실제 위반은 없습니다.

기존 `hotfix-verification`과 `visualization` 기능은 code가 Markdown 스킬 문서를 가리킵니다.
이번에 확정한 확장자 규칙은 이 두 페이지를 `unknown-language`로 분류합니다.
전체 명세 29페이지 중 27페이지를 검사했고 2페이지는 미검증입니다.
이 결과를 통과로 바꾸거나 기존 다른 이슈의 명세를 수정하지 않았습니다.
따라서 저장소 전체 형상 검사와 이를 사용하는 새 PR 게이트는 완료로 판정하지 않습니다.
이 문서 기반 기능의 판정 범위는 별도 합의가 필요합니다.

Seed 원본 사례 전체와 원격 CI는 미검증입니다.
실제 GitHub drift 이슈의 생성·종료는 실행하지 않았습니다.
패키지 설치·릴리스·머지는 이 작업의 검증 범위에 포함하지 않았습니다.
