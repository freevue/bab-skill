# PR 문서 품질 리포트

PR은 기준 브랜치에 없던 문장 규칙 위반을 Actions 요약에 보여줍니다. 문장 위반은 보고만 하고, 검사 실행 오류는 실패로 남깁니다.

## 구성 유닛

| 유닛 | 역할 |
| --- | --- |
| [diffProse](../unit/prose/diffProse.md) | 기준·PR 문서의 위반을 대조합니다 |

## 흐름

1. PR workflow가 변경본과 기준 커밋을 각각 체크아웃합니다. 검사 스크립트는 배포된 bab 태그에서 가져옵니다.
2. `diffProse`는 두 저장소에서 `wiki/`, `docs/`, 루트 `README*.md`, `plugins/bab/skills/`의 일반 Markdown 파일만 읽습니다. 심볼릭 링크와 삭제한 파일은 읽지 않습니다.
3. 내용이 같은 문서는 건너뛰고 바뀐 문서만 같은 `prose-check`로 검사합니다. 경로·규칙·상세·위반 시작 줄의 검사 대상 문장을 키로 쓰고 중복 횟수까지 대조합니다. 줄 번호만 이동한 기존 위반은 새 위반이 아닙니다.
4. 새 위반의 경로·줄 번호·규칙·상세를 Actions 요약에 적습니다. 문장 위반이 있어도 이 단계는 성공합니다.
5. 저장소 입력이나 실행이 잘못되면 오류를 표시하고 종료 코드 2를 반환합니다. 문장 검사 통과만으로 의미 보존을 주장하지 않습니다.
